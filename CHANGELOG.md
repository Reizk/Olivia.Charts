# Changelog

## 0.1.0-alpha.4

First public preview of Olivia Charts.

- MIT-licensed chart models and Avalonia controls for .NET 8.
- A desktop gallery with 24 examples across basic, area/range, hierarchy, time/finance, and live/large-data charts.
- Pointer-centered zoom and drag navigation for bar and scatter charts.
- Eight-channel sensor monitoring with pause, history browsing, and live following.
- Light and dark themes, a forest green identity, and English and Chinese project documentation.
- Contribution guidelines, issue templates, security reporting, and third-party license notices.

This is an alpha release. APIs may change. The demo interface is currently in Chinese, and 3D examples are not shown in the gallery. Windows desktop rendering is checked locally; Windows and Linux automated checks run in CI. Native Linux and macOS desktop interaction have not been fully validated.

Versions alpha.1 through alpha.3 were private development iterations. See the [validation history](docs/VALIDATION.zh-CN.md) for the checks recorded during those iterations.
