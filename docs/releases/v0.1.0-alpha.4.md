# Olivia Charts 0.1.0-alpha.4

The first public preview of Olivia Charts: MIT-licensed chart models and Avalonia controls for .NET 8.

## Highlights

- 24 interactive examples covering basic charts, area and range charts, hierarchies, time series, financial charts, live signals, and large datasets.
- Eight sensor channels in four panels, with pause, history browsing, and live following.
- Pointer-centered zoom and drag navigation for bar and scatter charts.
- Light and dark themes, English and Chinese documentation, contribution guidelines, and issue templates.

## Downloads

| File | Use |
| --- | --- |
| `Olivia.Charts.Demo-0.1.0-alpha.4-win-x64.zip` | Windows x64 demo. Install .NET 8 Runtime (x64), extract all files, and run `Olivia.Charts.Demo.exe`. An SDK is not required. |
| `Olivia.Charts.Core.0.1.0-alpha.4.nupkg` | Chart models and calculations for a local NuGet source. |

| `SHA256SUMS.txt` | SHA-256 checksums for the three assets above. |

The demo contains locally generated data and includes its third-party license notices. Library packages are attached here and have not been published to nuget.org.

## Validation and scope

Local Release build passed with no warnings or errors. All 1,136 Core and 103 Headless tests passed, as did 24-page light/dark desktop rendering and an external package consumption check. GitHub Actions checks Windows and Linux separately.

This is a pre-release, and APIs may change. The demo UI is currently in Chinese. 3D examples are hidden. The Windows executable is not code-signed; native Linux/macOS desktop interaction has not been fully validated.
