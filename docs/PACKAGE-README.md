# Olivia Charts

MIT-licensed chart models and Avalonia controls for .NET 8.

- `Olivia.Charts.Core` provides chart data models, geometry, aggregation, and streaming sessions.
- `Olivia.Charts.Avalonia` provides Avalonia chart controls and references Core automatically.

Explore common charts, time series, financial charts, live sensors, and million-point curves in the [24-example demo](https://github.com/Reizk/Olivia.Charts).

This is an alpha preview; APIs may change. Source namespaces are `Olivia.Core.*` and `Olivia.Avalonia.*`. Avoid referencing overlapping types from the original `Olivia.Core` or `Olivia.Avalonia` assemblies in the same application.
