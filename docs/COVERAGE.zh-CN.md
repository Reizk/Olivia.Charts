## 与原演示程序的差异

新 Demo 专注于图表能力和统一浏览体验，不复刻旧综合 Demo 的每一个编辑界面。以下底层 API 已随源码保留并有相应核心回归测试，但新 Demo 暂未提供完整操作入口：

- 金融图完整文本/图片标注编辑器，以及独立的实时行情页面。
- 工作区配置文件保存、读取和完整配置编辑器。
- 历史数据 CSV/JSON 导出按钮。
- 坐标精度专用展示页。

平滑曲线示例使用每序列 8 个点，遵守现有几何工作预算。实时示例每 100ms 推进一批合成数据，目的是展示状态和生命周期；没有将该频率当作刷新率或性能指标。

金融图的标注工具是否允许当前操作，由底层控件按数据和周期状态决定。参数切换、主题切换及销毁经过自动化检查；物理鼠标逐项绘制和旧编辑器的全部交互流程没有计入本次验收。
