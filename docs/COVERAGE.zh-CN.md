# 图表与 Demo 覆盖范围

2026-10-26，公开预览版 0.1.0-alpha.4。

| 分类 | 新 Demo 页面与能力 |
| --- | --- |
| 基础图表 | 曲线（平滑/折线/阶梯）、柱状、散点、饼/环、雷达、迷你趋势图 |
| 面积图表 | 面积、平滑曲线、堆叠面积、平滑堆叠、阶梯堆叠、区间 |
| 层级与关系 | 热力、树图、旭日、流向 |
| 历史数据 | 历史曲线、范围导航、双轴、多序列 |
| 金融 | 合成 OHLC、周期聚合、布林带、成交量、CCI、Williams %R、四种绘图工具 |
| 实时与规模 | 4 窗格 8 路传感器、实时散点、两条各 100 万采样点的曲线 |

24 个页面均提供明暗主题。“三维图表”和“数据与配置”分类已从 Demo 导航与搜索中隐藏。工作台提供统一工具栏与可折叠参数面板，小窗口默认收起参数以保留图表空间。带动态数据的页面支持暂停，支持重置的控件提供重置按钮；切换页面和关闭窗口时释放旧数据源与后台工作。

八路传感器在实时状态下缩放仍跟随新数据；拖动或左右键进入手动历史窗口，采集继续，界面明确显示状态。“回到实时”按钮或 Home 键恢复跟随；暂停与继续独立于时间窗口。Demo 补齐缩放、平移、拖动窗口及恢复跟随的全部控件事件。

柱形图的四种排列方式均可围绕鼠标位置滚轮缩放，并左右拖动访问全部类别；连续放大可到单个类别。静态和实时散点均支持鼠标位置缩放及双轴拖动，原始点的数值和点击选择不变。右侧的放大、缩小按钮使用视口中心，Home 或“重置视图”恢复全图。

## 与原演示程序的差异

新 Demo 专注于图表能力和统一浏览体验，不复刻旧综合 Demo 的每一个编辑界面。以下底层 API 已随源码保留并有相应核心回归测试，但新 Demo 暂未提供完整操作入口：

- 金融图完整文本/图片标注编辑器，以及独立的实时行情页面。
- 工作区配置文件保存、读取和完整配置编辑器。
- 历史数据 CSV/JSON 导出按钮。
- 坐标精度专用展示页。
- 三维曲面和三维散点；因当前交互流畅度不足，Demo 暂不展示，库 API 保留兼容。

平滑曲线示例使用每序列 8 个点，遵守现有几何工作预算。实时传感器和实时散点每 100ms 推进一批合成数据，目的是展示状态和生命周期；没有将该频率当作刷新率或性能指标。

金融图的标注工具是否允许当前操作，由底层控件按数据和周期状态决定。参数切换、主题切换及销毁经过自动化检查；物理鼠标逐项绘制和旧编辑器的全部交互流程没有计入本次验收。
