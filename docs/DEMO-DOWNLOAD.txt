Olivia Charts Demo

Windows x64 public preview

1. Install the .NET 8 Runtime for Windows x64:
   https://dotnet.microsoft.com/en-us/download/dotnet/8.0
2. Extract the entire ZIP into a folder.
3. Run Olivia.Charts.Demo.exe.

An SDK is not required. Keep the DLLs, native libraries, and other files
together with the executable. This preview is not code-signed.

The demo contains 24 examples with locally generated sample data.
Its interface is currently in Chinese. Use the theme button at the top
to switch between light and dark appearances.

Source, English and Chinese guides, and issue reporting:
https://github.com/Reizk/Olivia.Charts
