# Security Policy

## Supported versions

Security fixes are targeted at `main` and the latest preview release. Earlier alpha releases do not receive separate backports. Olivia Charts is currently a development preview.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Reizk/Olivia.Charts/security/advisories/new) to send a report to the repository maintainers. Include the affected version, a minimal reproduction, the expected impact, and relevant environment details. Use synthetic data and redact secrets.

Do not disclose an unpatched vulnerability, exploit, or private user data in a public issue or pull request. Ordinary chart bugs without security impact belong in the issue tracker.

This project does not currently offer a bug bounty or a guaranteed response time. Maintainers will assess reports and coordinate fixes and disclosure with reporters.
