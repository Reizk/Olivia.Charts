# Demo 图标

2026-10-25 改用用户提供的墨绿底、米金色 O 形柱状图标。原件完整保存，仅做等比例缩放和 ICO 格式转换；保留图案、构图和背景。

- `chart-icon-source.png`：用户提供的 1254×1254 PNG 原件，逐字节复制。
- `chart-icon.png`：256×256，供 Avalonia 窗口和顶栏加载。
- `chart-icon.ico`：16、24、32、48、64、128、256 像素，用于 Windows 程序图标。

Demo 主色为墨绿 `#0C432D`，品牌文字使用米金 `#F4E9D2`。浅色界面采用暖白和浅绿，深色界面采用暗绿和较亮的绿色强调色。主按钮单独使用深绿底与浅色文字，以保证两种主题下的可读性。

旧圆形曲线图标及其生成记录保留在 Git 历史中。
