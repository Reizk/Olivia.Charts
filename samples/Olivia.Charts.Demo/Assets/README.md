# Demo 图标

圆形蓝底、白色曲线和青色数据节点，与图表工作台配色统一。2026-10-25 使用内置 imagegen 生成；仅做缩放和文件格式转换，保留透明背景和生成原件。

- `chart-icon-source.png`：生成原件。
- `chart-icon.png`：256×256，供 Avalonia 窗口和顶栏加载。
- `chart-icon.ico`：16、24、32、48、64、128、256 像素，用于 Windows 程序图标。
